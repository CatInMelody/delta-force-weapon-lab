# 三角洲行动枪械基础图标

共 55 张透明背景 PNG，每把枪一个基础图标，不含皮肤和配件。
所有 PNG 均下载自腾讯 playerhub.df.qq.com 公共 CDN；保留下载原字节、原始尺寸和透明通道，没有裁切、放大或重绘。

文件用枪名命名，例如 AR/M4A1.png、SMG/MP5.png、DMR/SR-25.png。
多数图标为 1200×600；少数较新枪械的原图尺寸不同，具体见清单。
分类按游戏资料目录，SVD 放在 DMR，SR-3M 放在 SMG。

目录以 DFTTK 的公开武器目录和中文名称数据为基础，并与另外两份枪械目录交叉核对。
另两份目录五类合计为 54 把，漏列 SR9；已通过独立物品图鉴核对并补入 DMR，共 55 把。
DFTTK 数据版本为 20261015-bd-balance.1。本目录记录采集时可核对的枪械，不包含未来更新。

sources.json：每张图的名称、分类、原图 URL、尺寸、透明通道及 SHA-256 校验值。
JSON 清单保留来源信息；旧 CSV 简表已清理。
