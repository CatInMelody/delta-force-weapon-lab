# 三角洲行动子弹图标与六色背景

采集日期：2026-10-24。

## 子弹图标

20 种口径各保存一个共享基础图标，直接放在 Bullet 文件夹。
共映射 110 种枪械弹药，等级 1—7 和赛季弹药按同口径复用图标。
目录另有 4 种复合弓箭矢；它们不属于本次“子弹”范围，没有混入。
图标保留下载原字节、原始尺寸和透明通道，没有裁切、放大或重绘。
其中 19 张为腾讯公开 CDN 原图，.357 Magnum 为已核对的 Orzice 公开透明图。
文件使用口径命名，例如 5.56x45mm.png、300-BLK.png、357-Magnum.png。

## 品质背景

Background 文件夹内有 6 张 512×512 PNG，不含文字、弹药图标或等级数字。
这些背景根据用户明确要求自行制作，属于自制渐变背景，不是游戏原版底图。

| 子弹等级 | 颜色 | 文件 |
|---|---|---|
| 1 | 白色 | Background/1级_白色.png |
| 2 | 绿色 | Background/2级_绿色.png |
| 3 | 蓝色 | Background/3级_蓝色.png |
| 4 | 紫色 | Background/4级_紫色.png |
| 5 | 黄色 | Background/5级_黄色.png |
| 6、7 | 红色 | Background/6-7级_红色.png |

界面中先显示背景，再在上层叠加对应的透明子弹图标。
6 级和 7 级共用一张红色背景；显示具体等级时由软件另加文字。

## 清单

- bullet-sources.json：口径、原图来源、尺寸、校验值、各等级背景映射。
- 弹药名称与图标映射以 bullet-sources.json 及 data/ 下的当前 JSON 为准。
- Background/backgrounds.json：6 张自制背景的颜色及等级映射。

游戏图标的版权归属和使用授权没有因为下载而改变；本次没有取得再分发或商用授权。
自制背景与下载的游戏图标在清单中分别标明来源。

数据来源：https://sjz.u79.cn/ammo/ 和 https://dfttk.com/data/v3/catalog/ammo.json 。
