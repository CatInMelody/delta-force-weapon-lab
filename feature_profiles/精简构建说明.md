# 精简构建

配置 `tool-release.gdbuild` 可在 Godot 的引擎编译配置编辑器中打开。基于官方 Godot 4.7.1 源码，以 MSVC 2022、`optimize=size lto=full debug_symbols=no` 编译。

保留 GDScript、GUI、中文文字排版、FreeType、PNG/JPEG/WebP/SVG、TLS/HTTPS 和 JSON。移除 Mono、3D、物理、导航、XR 与未使用模块，使用 Compatibility / OpenGL 渲染。

发布脚本为 `tools/build_release.ps1`，首次带 `-CompileTemplate` 编译无密钥模板 `export_templates/tool.plain.windows.template_release.x86_64.exe`。之后不带此参数即可重新导出。必须传入 `-GodotEditor` 指定本机 Godot 控制台程序路径。

当前发布不加密 PCK，不生成 ZIP，不读取私密密钥或导出凭据。PCK 内嵌于 EXE，许可文件一起打包，可在更新页查看。旧的加密版模板不用于当前发布。

默认窗口 2074×1166，禁用边框缩放；逐文本白色扫光保留。编译源码、中间文件、发布数据包、测试、文档、密钥与导出工具均排除在 EXE 外。
