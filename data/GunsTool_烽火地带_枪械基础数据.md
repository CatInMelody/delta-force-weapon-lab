# 三角洲行动：烽火地带枪械基础数据

**采集日期：2026-10-24。数据版本：`20261015-bd-balance.1`。**

- 模式：烽火地带（sol）。对象：未改装、未精校的基础枪械。
- 射程记录面板优势射程，单位为米；不是最大射击距离，也不直接等同于伤害模型的无衰减距离。
- 射速单位为发/分钟，取烽火地带 combatSummaryByMode.sol.displayFireRateRpm；点射枪采用包含点射间隔的显示/持续射速。
- 甲伤和肉伤分别为枪械基础护甲伤害、基础伤害。实际命中结果还受弹药、命中部位、护甲、距离等因素影响。
- 数值来自社区维护的数据集，已核验下载文件与其版本清单的 SHA-256 一致；未逐把在游戏中实测，不能据此保证与后续热更新完全同步。
- 覆盖此前收集图标的 55 把枪：步枪 24、狙击枪 5、冲锋枪 12、射手步枪 10、轻机枪 4。

## 来源与字段

- 主数据：[DFTTK](https://dfttk.com/)，[版本清单](https://dfttk.com/data/v3/manifest.json)。
- [烽火地带战斗数据目录](https://dfttk.com/data/v3/catalog/weapons.json?v=65089f0628197d53)：`combatSummaryByMode.sol` 下的 `displayFireRateRpm`、`baseArmorDamage`、`baseFleshDamage`。
- 优势射程：各武器的 `packs/build-shared/cores/{weapon_id}.json` 中 `payload.weapon.attributes.displayAttrValues["2"]`；逐枪 URL 和校验值保存在 JSON 中。
- [AWM 交叉参考](https://orzice.com/v/info/406)：优势射程 200 米、射速 35、甲伤 10、肉伤 100。
- [枪械图鉴交叉参考](https://www.dfhub.cn/gun-codex)：用于核对部分枪械与点射射速；未用该页面替换主数据。

## 用于软件

- JSON 包含武器 ID、类别和图标相对路径，可与 `E:\GunsTool\assets` 内图片关联。
- CSV 使用 UTF-8 BOM 编码，方便用 Excel 打开。
- 更新时应重新获取同一份版本清单对应的数据；当前导出是采集日的来源快照。
