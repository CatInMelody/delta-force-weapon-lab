# 烽火地带：防具耐久与弹药甲伤系数

采集日期：2026-10-24。来源数据版本：`20261015-bd-balance.1`。

## 文件与格式

- `defense_stats.json`：26件护甲、27件头盔，按字符串物品ID索引。
- `ammo_armor_factors.json`：20种口径、110种子弹，每种都有对1～6级甲/头盔的完整系数。
- `defense_ammo_sources.json`：来源URL、字段映射、源文件SHA-256与版本。
- 文件统一UTF-8无BOM，标准JSON，无注释、无尾逗号。物品ID和字典等级键是字符串；伤害系数、耐久、等级是数值。
- 主数据仅使用JSON，避免Godot把CSV自动识别为翻译表。

## 系数口径

数组顺序固定为 `[1级甲, 2级甲, 3级甲, 4级甲, 5级甲, 6级甲]`，下标为 `护甲等级 - 1`。

你举的 `.300 BLK V-Max` 三级弹已核对：`[0.9, 0.9, 0.9, 0.9, 0.5, 0.4]`；同为三级的 V-SUB 本次快照也是这组数值。

- `armor_damage_factors`：对各级身甲的耐久伤害修正系数；0.9表示保留90%，1.1表示放大至110%。
- `helmet_damage_factors`：对各级头盔的耐久伤害修正系数。
- `ammo_armor_damage_multiplier`：子弹自身独立甲伤倍率。
- `effective_armor_damage_factors`：独立倍率与对应身甲修正系数的乘积，已经包含独立倍率。
- `effective_helmet_damage_factors`：独立倍率与对应头盔修正系数的乘积。
- 同口径同等级可能包含不同弹种，索引返回ID数组，必须选具体弹种。比如5.56x45mm三级M855和M855 APC不可合并。

按来源模型，命中受保护部位时的理论甲伤 = 枪械基础甲伤 × 弹药独立甲伤倍率 × 对目标等级的耐久修正系数 × 其他适用的部位/距离修正。

也可用枪械基础甲伤 × `effective_armor_damage_factors[甲等级-1]` 再处理其他修正。切勿额外再乘一次独立倍率。实际扣除耐久最多为目标当前剩余耐久。

这些值不是肉伤穿透系数；特殊弹附加效果、散弹/双头弹多弹丸、破甲溢出等需要另外处理。`effective_*`为来源模型计算结果，未经本次游戏实测。

## Godot 4读取示例

```gdscript
var defense_data: Dictionary = JSON.parse_string(
    FileAccess.get_file_as_string("res://data/defense_stats.json")
)
var ammo_data: Dictionary = JSON.parse_string(
    FileAccess.get_file_as_string("res://data/ammo_armor_factors.json")
)
var titan: Dictionary = defense_data["armors"]["11050006004"]
print(titan["max_durability"]) # 150
var bullet: Dictionary = ammo_data["ammo"]["37280300001"] # .300 BLK V-Max
var armor_level := 5
var factor := float(bullet["armor_damage_factors"][armor_level - 1])
print(factor) # 0.5
# 同口径同等级可能有多个弹种：
var choices: Array = ammo_data["by_ammo_type_and_level"]["27"]["3"]
# choices中每项为字符串弹药ID。
```
